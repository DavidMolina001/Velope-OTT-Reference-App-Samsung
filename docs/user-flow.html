Reference App user flow.

Every screen of the Samsung TV reference app and, for each button on the remote, where it takes you. It describes the build installed on the test TV today. Features that were tried and removed (saved favourites list, static launch image) are not part of it.

The rules behind it

Four behaviours hold across every screen.

Back steps one level up

Player to where you came from, details to rows, rows to hero, hero or menu to the exit dialog.

Exit always asks first

The remote's Exit key opens the exit dialog from anywhere, even mid-video. No is preselected.

OK depends on commitment

A quick OK on a tile opens details. After 7 s of preview, OK keeps watching. On the hero, Play always plays.

Nothing moves while you press

Previews stop the moment you move. The hero only advances after 7 s with no key press.

Worth confirming with the team

  • Back from a player opened from a tile preview goes to the details page, not back to the row.
  • The + / Add to favourites buttons only remember until the app closes; there is no saved favourites list.
  • Every preview and every Play uses the same test video (Big Buck Bunny).
